# 2026-11-02

## 오늘 한 것
- 회원 생성 흐름에서 Controller, Service, Domain의 책임을 학습
- HTTP 요청 DTO와 Service 입력 Command를 분리
- Service가 Member를 반환하고 Controller가 응답 DTO를 구성하도록 흐름 정리
- 학습 내용을 기억에서 꺼내 설명하며 복습

## 학습한 내용
- Controller는 HTTP 요청과 응답을 다룬다.
- Service는 유스케이스의 흐름을 조율하고, Member는 자신의 상태와 생성 규칙을 관리한다.
- `MemberCreateRequest`는 HTTP JSON 입력을 표현한다.
- `CreateMemberCommand`는 회원 생성 유스케이스에 필요한 입력을 전달한다. 두 입력은 지금 필드가 같지만 변경 이유와 경계가 다르다.
- Service가 HTTP 응답 DTO를 만들지 않고 Member를 반환하면, HTTP 응답 표현을 Controller에 둘 수 있다.
- 현재 `1L` ID는 저장소가 없는 동안의 임시 값이며 실제 생성 ID가 아니다.
